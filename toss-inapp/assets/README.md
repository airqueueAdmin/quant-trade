# Toss Console Assets

업로드 대상:

- `logo-light-600.png`
  - 앱 로고
  - 권장 크기: `600x600`
- `logo-dark-600.png`
  - 다크모드 앱 로고
  - 권장 크기: `600x600`
- `thumbnail-1932x828.png`
  - 썸네일
  - 권장 크기: `1932x828`

콘솔 입력용 텍스트 추천:

- 앱명: `한눈투자`
- 짧은 소개:
  - `시장 흐름을 한눈에`
  - 또는 `뉴스부터 전략 연습까지`
- 검색 키워드:
  - `투자, 주식, 섹터, AI분석, 뉴스요약, 전략연습, 백테스트, 모의투자, 시장흐름`

스크린샷 권장 구성:

1. 홈 화면
2. 섹터 흐름
3. AI 분석 결과
4. 전략 연습
5. 모의투자

비고:

- 스크린샷은 실제 앱 화면을 캡처해서 올리는 편이 심사 대응에 안전합니다.
- 세로형은 최소 3장, 가로형은 최소 1장 준비합니다.
